# EnoGym 1.0.5

- 「设置 → 关于」新增更新日志，可离线浏览 EnoGym 和 GymMane 的版本要点，并查看本包合入的上游版本与提交。
- 修复普通备份轮转可能误删其他设备同步文件的问题。
- 同步优先保护未备份的本地编辑；服务端并发保存及导入期间的新编辑不再相互覆盖。
- 同步失败可以重试，媒体写入失败不会留下已处理标记；重复照片复用，避免同名图片串用。
- 修复默认偏好无法从较新快照恢复的问题。
- 补齐桌面小组件首次添加所需的缓存与刷新；普通刷新继续只处理已安装的小组件。
- 未完成训练按原始起点恢复计时，取消超过 6 小时固定记为 3 小时的处理，保留已确认组记录。

沿用现有精简界面和导入导出功能，包名及签名不变。升级采用覆盖安装，不卸载、不清理数据。此前已被旧版截短且保存的时长没有可靠原始依据，本版不会猜测或改写历史。
