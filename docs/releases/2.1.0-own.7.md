新增应用内更新：设置 → 关于 → 检查更新。

- 手动检查 GitHub Releases，查看版本说明并下载更新。
- 下载完成后校验文件、包名、版本和签名，再交给 Android 系统安装。
- 下载失败可重试；已校验的下载可重复使用。正在训练时暂不安装。
- 训练和数据保存继续离线工作，不上传训练记录。

首次请下载安装本页的 arm64-v8a APK，直接覆盖现有 EnoGym，不要卸载或清除数据。以后可在应用内检查更新。首次在应用内安装时，Android 可能要求允许 EnoGym 安装未知应用；授权后返回并再次点击「安装更新」。
