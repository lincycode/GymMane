# EnoGym 1.0.6

- 记录 RPE 时，用刻度尺选择还能标准做几次，下方实时显示换算后的 RPE。第一组默认 2 次，后续带出同一动作最近一组填过的值。
- 修复肌肉热力图统计不一致的问题。斜方肌等次要肌群有正式组记录时，「未练」会显示最近练到的日期。
- 休息结束提示在训练控件下方滑入，绿色计时器外圈闭合，可点按关闭。底栏的选中标签与中间训练按钮之间留出更多距离。
- 「设置 → 关于 → 更新日志」显示 EnoGym 各版的日期。
- 同步 GymMane 2.2.0。动作库支持复制动作，热身组从训练量和力量纪录中排除，CSV 增加组类型和 RIR。

已安装 EnoGym 时，可从「设置 → 关于 → 检查更新」下载，或用下方 arm64 APK 覆盖安装并保留训练记录。
