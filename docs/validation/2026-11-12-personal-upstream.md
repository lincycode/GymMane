# EnoGym 1.0.4 验证

个人版精简基于 `36273e7`，合入 GymMane 主分支 `f7fd2ba`。原作者最新正式标签仍为 `v2.1.0`。Android 安装包使用原有 `com.echolin.gymmane` 包名和相同 Release 证书，arm64 版本码由 142 升至 152。

- Flutter 静态分析通过。合并后的完整测试 1145 项通过，3 项跳过。修正首页工具说明后，首页、界面、更新器和备份相关 69 项测试通过。
- `packages/sync` 的 4 项测试及 `server` 的 8 项测试通过。Web JavaScript 构建通过。Wasm 预检查提示 `video_player_web` 的 JS 类型检查兼容性，未验证 Wasm 构建和实际部署。
- 隔离 Android 17 模拟器从 1.0.3 同签名覆盖升级，核对两次合成历史、三套训练方案、排程、暂停会话和偏好。导出 ZIP 中的历史与升级前一致，导入和 CSV 入口仍可见。
- 通用页的两个显示选项可独立修改并在重启后保留。「关于」有版本、检查更新和署名。首页饮食入口可见，个人资料优先展示历史。已安装周计划小组件的图像正常刷新。
- 自动备份页默认显示「立即备份」，共享文件夹同步开关关闭。测试覆盖旧自动备份配置默认关闭同步，以及暂停会话期间拒绝同步合并。未连接实际 Syncthing 文件夹。

真机、Wear OS、耗电和大量历史下的运行表现仍待验证。
