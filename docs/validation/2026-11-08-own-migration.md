# EnoGym 首轮迁移验收

日期：2026-11-08。上游基线：`v2.1.0 / 46d51f25415fe59415b330b851942e65923674ca`。本轮重新获取上游分支与标签，`upstream/main` 与该基线一致。

## 实现范围

- 新建个人 fork、`own` 与短期开发分支；`main` 跟踪 `upstream/main`。个人代码尚未推送。
- 独立 Android 安装身份、外部固定 Release 签名和个人版本配置；保留 Kotlin namespace、原有数据模型、存储和备份格式。
- 首页周概览附近可进入计划页；创建入口前移，区分周安排、轮换、训练方案、模板和已保存周计划。
- 模板先预览，确认才写入；解析缺项阻止整套添加，取消不写入，连续确认只添加一次。
- 只有固定周且无现有安排、额外安排或日期调整时可选择自动排周；已有周计划和轮换顺序受保护。
- 未导入 EnoLift 数据或 openGym 代码、素材。生产首次使用没有预置训练历史。
- 品牌为 EnoGym、定制与维护为 Enoch；跑者图标融入 E，成就系统保留，原作者法律署名与许可保留。
