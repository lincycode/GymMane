# RPE 输入验收

按次数的动作在训练中通过原有刻度尺选择还能标准做几次。主读数带单位，正下方实时显示换算后的 RPE。第一组默认 2 次，后续按同一动作最近已填的一组预填，热身组和正式组各自取值。编辑已有值时先显示该组的记录。保存才写入 RPE，取消时仅关闭弹窗。

Android 模拟器上覆盖安装 Debug 包后，合成训练草稿可继续编辑。滑尺能从 2 次调到 0 次，预览从 RPE 8 更新为 RPE 10。四组保存的 RPE 依次为 8、8、10、10，第四组仍可单独标记完成。回归测试验证最后一组的输入弹窗关闭后才自动写入历史。

- Flutter 全量测试 1167 项通过，3 项私有样本测试跳过。专项回归 110 项通过，静态分析与 Android arm64 Debug 构建通过。
- 运行日志和界面对照在本地 `artifacts/qa/2026-11-13-reps-in-reserve/`。本轮验收使用隔离模拟器和合成数据。
