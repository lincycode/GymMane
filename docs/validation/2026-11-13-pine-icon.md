## 修改范围

- 精修全身跑者轮廓，统一松绿 `#103D2C` 与奶油色 `#FFF2D5`，保留抗锯齿边缘与约 76% 的主体高度。透明前景与实底图分别导出，避免透明边缘二次混合造成暗边。
- 统一 README、关于页、宽屏侧栏、月度回顾、分享贴纸、PDF 标记与水印、Android 启动器及通知、Web favicon/PWA/Apple touch icon、iOS AppIcon 与 Live Activity 资源。宽屏侧栏和 Web 启动画面同步使用 EnoGym 名称。
- 新增 Android 单色主题图标。Web maskable 独立留出安全区；iOS AppIcon 保持不透明。
- 生成器共用 `lib/app/own_build.dart` 的颜色和路径；默认配置与个人配置一致。补充生成来源、维护说明和设计文档，保留原作者署名及旧原稿。
- 首页、引导页和训练完成页的原版装饰插图不是品牌图标，保持不变。训练、存储、签名、包名、版本及备份逻辑未修改。
