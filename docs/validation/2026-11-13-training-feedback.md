# 训练反馈验收

用一条包含 16 组哑铃俯身侧平举的合成记录，在 Ace 6T（Android 17）上的 EnoGym Debug 复现。旧版「本周」给次要肌群斜方肌计 8 组，「未练」只查主要肌群，显示「还没练过」。覆盖安装后，「本周」仍是 8 组，「未练」显示「今天练过」。测试历史、周计划和训练方案在覆盖前后相同。

同一台手机上实测休息倒计时自然结束。提示在训练控制键下方出现，计时器外圈闭合，随后自动消失，也可点按关闭。进度和动作库的选中底片均与中间按钮分开，两个标签和开始训练均可正常点按。

- Flutter 全量测试 1165 项通过，3 项私有样本测试跳过。静态分析无问题，Android arm64 Debug 构建通过。
- 回归测试覆盖次要肌群、热身组、有氧训练、未来日期、窄屏底栏间距、减少动画和关闭提示。
- 对照截图、短录屏和日志在本地 `artifacts/qa/2026-11-13-feedback/`。真机验证使用独立 Debug 包和合成记录，正式版覆盖升级及其他平台未在本轮验收。
